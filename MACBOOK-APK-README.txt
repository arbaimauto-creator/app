GREYD APK - MacBook 실행 안내

파일: greyd-representative-arm64-release.apk
지원 환경: Apple Silicon MacBook (M1/M2/M3/M4), Android Studio ARM64 에뮬레이터

1. Android Studio를 설치합니다.
2. Device Manager에서 ARM64 기반 Android 15 가상 기기를 생성하고 실행합니다.
3. greyd-representative-arm64-release.apk 파일을 실행 중인 에뮬레이터 화면으로 끌어다 놓습니다.
4. 설치가 끝나면 에뮬레이터 앱 목록에서 GREYD를 실행합니다.

터미널 설치 방법:
adb install -r greyd-representative-arm64-release.apk

참고:
- APK는 macOS 앱이 아니므로 Finder에서 직접 실행할 수 없습니다.
- Intel Mac의 x86_64 에뮬레이터에서는 실행할 수 없습니다.
- 실제 arm64 Android 스마트폰에도 설치할 수 있습니다.
