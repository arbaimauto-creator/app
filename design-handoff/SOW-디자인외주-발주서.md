# [발주서] greyd 모바일 앱 UI 디자인 — 비주얼 시스템 구축 및 38화면 하이파이 시안

## 1. 프로젝트 한 줄 요약

한국 브랜드가 글로벌 크리에이터의 리뷰를 직접 읽고 평가하는 **초대제 리뷰 패널 앱 "greyd"** 의
Phase 1 화면(모바일 32 + 웹 콘솔 6)에 대한 **비주얼 디자인 시스템 구축 + 하이파이 시안 제작**.

> ⚠️ 기획·UX·와이어프레임·카피는 **모두 완료**되어 있습니다.
> 요청 범위는 리서치나 화면 설계가 아니라 **비주얼 스킨과 디자인 시스템**입니다.

## 2. 발주사가 이미 준비한 것 (착수일에 전달)

| 자료 | 내용 |
|---|---|
| 화면 설계 문서 (웹) | 전 38화면 와이어프레임 + 확정 카피 + 화면별 기획 근거 |
| 아트 디렉션 후보 2안 | A. 블랙 카드 프리미엄 / B. 라이트 에디토리얼 — 핵심 3화면에 적용한 비교 시안 포함 |
| 디자인 토큰 | 브랜드 컬러(#FFB731 계열)·시맨틱 컬러·간격 (Tokens Studio JSON) |
| 서체 | Pretendard 전 웨이트 TTF (앱 번들 폰트) |
| 현행 앱 스크린샷 | 참고용 8종 |
| 기획서 | 서비스 정의·정책·데이터 스키마 (필요 시 열람) |

## 3. 작업 범위

### 1차 — 디렉션 확정 + 디자인 시스템 + 핵심 10화면 (약 1.5주)

1. 제공된 아트 디렉션 A/B 중 1안(또는 절충안)을 기반으로 **비주얼 디렉션 정교화**
2. **디자인 시스템**: 컬러 팔레트(라이트/다크), 타입 스케일, 버튼·카드·배지·입력 필드 등 공통 컴포넌트 (피그마 컴포넌트/변수로 구축)
3. **핵심 10화면 하이파이**: 초대 게이트(2) · 온보딩(2) · 체험 목록 · 캠페인 상세 · 활동 · 완주 보상 · 브랜드 대시보드 · 브랜드 평가(트리아지)

### 2차 — 전 화면 전개 + 핸드오프 (약 2주, 1차 검수 통과 후 착수)

4. 나머지 28화면 전개 (인벤토리 표 기준: 인플루언서 25 · 브랜드 7 · 운영 콘솔 6)
5. 상태 변형: 빈 상태·에러·로딩 (설계 문서에 명시된 것)
6. **개발 핸드오프**: 피그마 원본(컴포넌트화) + 스타일 가이드 1페이지

### 범위 제외 (별도 협의)

- 로고·BI 리뉴얼, 모션 그래픽 제작, 마케팅 소재
- 영문 카피 원어민 감수 (발주사 별도 진행)
- 운영 콘솔 6화면은 **로우파이 허용** (2단계 구현 예정 — 레이아웃 정확도만 요구)

## 4. 산출물 및 납품 조건

1. **피그마 원본 파일** — 컴포넌트·변수(토큰) 구조 필수. 플랫 이미지로만 구성된 파일은 납품 불인정
2. 디자인 시스템 페이지 (컬러·타입·컴포넌트 정리)
3. 화면 인벤토리 전 항목(38화면) 커버 — 발주사가 제공하는 인벤토리 표가 검수 체크리스트로 사용됨
4. 사용 서체는 Pretendard 유지 (디스플레이용 세리프 추가 제안은 환영)

- 검수 기준: 화면 인벤토리 전 항목 완성 + 디자인 시스템 일관성 (동일 컴포넌트가 화면마다 다르게 그려진 경우 미완성으로 간주)
- 수정: 차수당 **전체 수정 2회** 포함 (사소한 오탈자·정렬 수정은 횟수 미산입)
- 중간 공유: 주 1회 이상 진행 상황 공유 (피그마 링크)
