# greyd Phase 1 — 피그마 편집 패키지

39화면 와이어프레임을 피그마에서 수정할 수 있게 만든 패키지입니다. 두 가지 경로 중 편한 쪽을 쓰세요.

## 경로 A — 편집 가능한 레이어로 임포트 (권장)

1. 피그마에서 **[html.to.design](https://www.figma.com/community/plugin/1159123024924461424)** 플러그인 설치 (무료)
2. 플러그인 실행 → **HTML 탭** → `greyd-phase1-design.html` 파일 내용을 붙여넣기 (또는 파일 업로드)
3. 임포트하면 전 화면이 **프레임·텍스트·사각형 레이어로 분해**되어 들어옵니다 — 텍스트 수정, 색 변경, 컴포넌트화 전부 가능
4. 화면이 많아 한 번에 무거우면: `screens-html/` 폴더의 화면별 개별 HTML을 하나씩 임포트하세요 (40개 파일, 파일명 = 화면 번호·이름)

## 경로 B — PNG 참조 트레이싱

`screens-png/` 폴더에 전 화면이 **2배율 PNG 40장**으로 있습니다 (파일명 = 화면 번호·이름).
피그마 캔버스에 드래그해서 참조 레이어로 깔고 그 위에 새로 그리는 방식 — 리디자인이 목적이면 이쪽이 오히려 깔끔합니다.

## 공통 재료

| 파일 | 용도 |
|---|---|
| `design-tokens.json` | [Tokens Studio](https://tokens.studio/) 플러그인으로 임포트 → 컬러·간격이 피그마 변수로 생성 |
| `fonts/` | Pretendard TTF 9종 — 시스템에 설치 후 피그마 재시작 (앱 번들 폰트와 동일) |

## 화면 구성 (40 프레임)

- **01~27**: 인플루언서 퍼널 (소셜 로그인 → 게이트 → 온보딩 → 홈(큐레이션) → 체험 → 활동 → 업로드 → 보상 → 마이 → 설정)
- **28~34**: 브랜드 퍼널 (온보딩 → 대시보드 → 트리아지 → 루브릭 → 마이)
- **35~40**: ARBAIM 운영 (greyd-ops 콘솔 요구사항 — 데스크톱 프레임)

## 주의

- 이 와이어프레임은 **구조·카피의 정본**입니다. 비주얼은 바꾸되 화면 구성 요소와 문구는 기획 확정본이므로 임의 삭제 금지 (변경 필요 시 발주사와 협의)
