## 추가 (9/14 저녁) — 쇼츠 UX: 리뷰가 다른 화면처럼 느껴지던 문제

대표 지적: "쇼츠에서 리뷰로 넘어갔다가 다시 쇼츠 리스트로 오는 게 각각 다른 화면. 인스타처럼 한 화면에서 리뷰가 덧붙고, 접든 펼치든 스와이프하면 다음 쇼츠로."

원인: 쇼츠 페이지 안에서 리뷰 상세가 "영상 아래로 스크롤한 위치"였고, 상세를 보는 동안 바깥 세로 페이저를 잠갔다. 오버레이 캡션엔 제목만 있고 리뷰 본문이 없었다.

| 변경 | 위치 |
|---|---|
| 캡션 = 제목 + 리뷰 본문(마크다운 기호 제거). 2줄 접힘 → 「더보기」로 12줄 + 해시태그, 「접기」 | `screens/VideoPageScreen/VideoOverlay.js` |
| 나머지 상세(상품·6점 평가·문의·댓글·연관 리뷰)는 같은 쇼츠 위 시트(Modal 86%)로. 닫으면 그 자리 | `screens/VideoPageScreen/DetailsSheet.js`, `index.js`(`isDetailsOpen`) |
| 페이지 안 세로 스크롤 제거(FlatList scrollEnabled=false), 페이저 잠금은 시크바 드래그 중에만 | `index.js`, `Components/VideoPageScreenWrapper.js` |
| 시크바 PanResponder가 Terminate에서 잠금을 안 풀어 페이저가 영구 잠기던 버그(예전엔 상세 스크롤이 우연히 풀어줌) | `patches/react-native-video-controls+2.8.1.patch` |

실측 함정(에뮬레이터): ① `Text.onPress`는 Android에서 clickable TextView가 돼 그 위에서 시작한 세로 스와이프를 삼킨다 → Touchable 래퍼 사용. ② `LayoutAnimation` 뒤 페이저가 터치를 못 받는 현상 → 캡션 토글에 LayoutAnimation 제거. ③ 개발 모드에서 `React.lazy` 상세를 처음 열면 Metro가 모듈을 추가 번들하며 앱 전체 리로드 → 직접 import.

검증(에뮬레이터): 캡션 펼침·접힘 각각에서 스와이프 → 다음 쇼츠, 상세 시트 열기/닫기 후 같은 쇼츠·페이징 정상. jest 86/86, 번들 컴파일 통과.
