# 앱 공통 사용성 개선

## 반영한 내용

- 홈: 아래로 당겨 새로고침, 실패 시 재시도, 예시 리뷰 안내, 홈 탭 재선택 시 맨 위로 이동.
- 검색: 진입 파라미터 없는 경우 처리, 검색어 공백 정리, 검색 중 표시, 해시태그 오류 처리, 이전 요청 결과 무시, 입력 삭제 시 결과 초기화.
- 탐색: 탭 생성 객체를 유지해 부모 업데이트 시 화면 재생성 방지. 탭 숨김 스타일을 직접 변경하지 않고 계산하며 선택 콜백이 없어도 동작.
- 공통 UI: 버튼 최소 높이 48, 필터 최소 높이 44, 버튼 로딩 지원, 선택 상태와 진행률의 스크린리더 지원.
- 뒤로 가기: 터치 영역 확대, 이전 화면 존재 여부 확인, 한국어·영어 접근성 이름.

## 검증

- Jest: 15개 테스트 스위트, 90개 테스트 통과.
- 변경 JS 파일 ESLint 오류 없음.
- git diff --check 통과.
- Android 기기 화면 검증은 실행 도구 부재로 미실시.

## 기기 확인 항목

1. 홈을 아래로 당겨 갱신하고 연결 실패 시 재시도 버튼 확인.
2. 검색 중 다른 검색어를 입력하거나 입력창을 비워도 이전 응답이 표시되지 않는지 확인.
3. 홈·체험·활동·마이 탭 이동 후 화면 상태와 하단 탭 복구 확인.
4. 공통 버튼과 필터를 사용하는 화면에서 확대된 터치 영역과 줄바꿈 확인.

이번 변경은 공통 사용성과 주요 탐색 흐름을 대상으로 한다. 모든 개별 화면의 시각적 재설계나 서버 기능 변경은 포함하지 않는다.
