# "단골" — 팔로우를 대체하는 그레이드 고유 관계 (2026-09-17 확정)

팔로우/팔로워를 "단골"(EN: Regular)로 대체한다. 단골은 근거 기반 신뢰 표시다:
그 리뷰어의 리뷰가 실제로 맞았다고 내가 확인한 뒤에만 맺을 수 있다.

## 1. 용어

| 기존 | 변경 |
|---|---|
| 팔로우하다 | 단골 맺기 |
| 팔로워 n명 | 단골 n명 |
| 팔로잉 목록 | 나의 단골 |
| 팔로워 목록 | 내 단골 리뷰어(나를 단골로 둔 사람이 아니라, 내가 단골인 리뷰어 관점 명칭은 화면 라벨에서 구분) |

EN: Regular / Become a regular / n regulars.

## 2. 성립 조건 — 적중(hit) 시스템

같은 리뷰어에게 **적중 2회**(정책 상수 `REGULAR_UNLOCK_HITS = 2`)가 쌓이면
그 리뷰어에 대한 "단골 맺기" 버튼이 열린다. 그 전에는 잠금 상태로 노출하고
현재 진행("적중 1/2")과 해제 방법을 그 자리에서 설명한다.

적중 1회로 인정되는 행동:
1. **구매 적중** — 리뷰의 추적 코드/구매 링크 경유 구매 후, 앱이 묻는
   "리뷰대로였나요?"에 "맞았어요" 응답. (기존 추적 코드 딥링크·클릭 집계·주문
   연결 인프라 재사용)
2. **도움 적중** — 리뷰를 저장(레퍼런스)한 뒤 재방문 시 "이 리뷰 도움됐나요?"에
   "도움됐어요" 응답.

같은 리뷰에 대한 중복 적중은 1회만 인정한다(리뷰 단위 dedupe).

## 3. 데이터·서버

- **관계 저장**: 기존 팔로우 API를 그대로 사용한다(서버 변경 없음). "단골"은
  클라이언트 표현·게이트 계층이다.
- **적중 기록**: 앱 로컬(Preference 기반 api/ 모듈) + 기존 ops 아웃박스 패턴으로
  서버 복구 시 동기화 큐에 적재. 키: `regularHits:{reviewerId}` →
  `[{videoId, type: 'purchase'|'helpful', at}]`.
- **승계**: 기존 팔로우 관계는 전부 단골로 표시한다(잠금 소급 적용 없음, 삭제 없음).

## 4. 화면 변경

1. **홈 카드(CuratedHome PostCard)**: Follow 버튼 → 단골 버튼 3-상태
   - 잠김: "적중 n/2" (탭하면 해제 방법 안내)
   - 열림: "단골 맺기"
   - 완료: "단골"(탭하면 해제 확인)
2. **UserPage / 마이 탭**: Followers·Following 라벨 → 단골 계열 라벨로 교체.
   FollowList 화면 재사용(라벨·빈 상태 문구만 교체).
3. **홈 스토리 레일**: "내 단골 리뷰어"의 새 리뷰 우선 정렬.
4. **적중 확인 프롬프트**: (a) 추적 구매 후, (b) 저장 리뷰 재방문 시.
   같은 리뷰에 두 번 묻지 않는다.

## 5. 2단계 (이번 구현 범위 아님)

- 받은 단골 수의 G점수/신뢰 구성요소 반영 — 서버 배포 + 어뷰징 방어(맞신뢰
  클러스터 탐지) 설계 후.
- 서로단골 승격(상호 단골 시 질문 우선 답변 등) — 유저 볼륨 확보 후.

## 6. 테스트

- 적중 카운트 누적·리뷰 단위 dedupe·2회 도달 시 해제 판정
- 기존 팔로우 승계(잠금 미적용) 경로
- 프롬프트 노출 조건(중복 질문 금지)
