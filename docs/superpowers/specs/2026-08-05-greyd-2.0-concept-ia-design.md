# Greyd 2.0 — 컨셉 피벗 & 앱 IA 설계

날짜: 2026-08-05 · 상태: 디자이너 미팅용 초안 (대표 컨셉 문서 기반)
비전 덱: https://claude.ai/code/artifact/8e25da90-7f28-4185-b0a3-b45a5dd3945e

## 1. 컨셉 (확정 — 대표 문서 요약)

**greyd — The Trust Platform for Curated Korean Products.**
SNS도 쇼핑몰도 아닌, 전 세계 사용자가 한국 제품을 직접 써보고 검증하는 플랫폼.

- 구조: 브랜드 → 전세계 체험단 → UGC 생성 → 검증 → **Greyd Score** → 판매
- 3단계: **Curated**(greyd가 선별) → **Verified**(크리에이터 실사용 영상 리뷰) → **Trusted**(AI+커뮤니티 데이터로 Score/Mark 부여)
- Greyd Mark: 브랜드가 사는 인증이 아니라 사용자가 만드는 인증
- 장기 자산: 세계 최대 K-Product 소비자 영상 데이터셋

## 2. 앱 IA 개편 (제안)

### 탭 구조: Before → After

| Before (기능 백화점) | After (검증 루프) |
|---|---|
| Home / B2B / Review(+) / Shopping / My Page | **Discover / Products / Try(중앙 CTA) / Activity / Profile** |

- **Discover** — 검증 영상 풀스크린 피드. 기존 틱톡형 피드(구현 완료)에 Greyd Score 배지·체험 신청 CTA를 얹음
- **Products** — Verified 제품 DB. Score·국가·카테고리 탐색. 제품 상세 = Score 리포트(인증서)
- **Try** — 체험단 캠페인 목록/신청/배송 추적/리뷰 미션. 리텐션의 심장. 중앙 강조 탭
- **Activity** — 내 미션 진행·포인트·Rank 승급 트랙
- **Profile** — Creator Rank 카드, 검증 이력, 설정

### 분리/제거
- B2B(브랜드 캠페인 관리) → **웹 대시보드로 이관** (앱에서 제거)
- 범용 Shopping 탭 제거 → 구매는 제품 상세의 단일 "구매하기" 진입점 (Phase 3 전까지 외부 링크 허용)
- 리워드는 독립 기능이 아니라 Activity의 승급 트랙 안으로 흡수

### 핵심 화면 4개 (디자이너와 우선 확정)
1. **Try 캠페인 목록/상세** — 모집 카드(남은 수량·마감·국가 조건) → 신청 → 승인/배송 → 미션 시작
2. **제품 상세 = Score 리포트** — Greyd Mark(점수/국가/영상 수) + 국가별 반응 + 긍/부정 키워드 + 검증 영상 그리드
3. **Discover 피드** — 기존 풀스크린 피드 + Score 오버레이 ("오락"이 아닌 "검증 열람" 톤)
4. **Creator Rank 카드** — 랭크·검증 횟수·승급 조건을 게임 패스 형태로

## 3. 로드맵

- **Phase 1 — 검증 루프 MVP**: Try(신청·배송·미션) + 리뷰 업로드 + Discover 피드. 운영은 기존 시딩 시스템, 앱은 그 창구
- **Phase 2 — Greyd Score & Mark**: AI 분석(감정·키워드·FGI Report), 제품 상세 리포트, 브랜드 웹 대시보드
- **Phase 3 — 커머스**: 검증된 제품만 인앱 판매 ("Verified만 판다")

## 4. 기존 코드베이스와의 관계

- 유지: 틱톡형 비디오 피드(VideoPageScreen 개편분), 인증/로그인, 업로드 파이프라인, G6 평가(→ Greyd Score의 입력으로 재해석)
- 신규: Try(캠페인) 도메인 — 화면·API 모두 신규
- 제거/이관: B2BScreen(웹으로), ShoppingScreen 탭, 독립 리워드 화면
