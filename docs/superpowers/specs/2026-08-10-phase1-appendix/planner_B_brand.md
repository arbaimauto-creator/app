# greyd 1단계 설계 고도화 — 브랜드사 가치 & 데이터 설계 관점

전제 정리부터. 이 제품의 1단계는 "인플루언서 마케팅 툴"이 아니라 **"1천만원짜리 글로벌 FGI 리서치 상품의 디지털 전달 채널"**이다. 브랜드사가 앱에서 느껴야 하는 것은 편리함이 아니라 **"4~5천만원짜리 리서치를 받고 있다는 증거"**다. 따라서 1단계 설계의 성공 기준은 딱 두 가지다.

1. **리포트가 서게 만드는 데이터를 빠짐없이 쌓는다** (세영의 질문에 대한 답)
2. **브랜드사가 앱을 열 때마다 "진행되고 있고, 발견이 나오고 있다"를 느끼게 한다** (2단계 3천만원 업셀의 근거)

---

## 1. 브랜드사 여정 — 단계별 화면 · 데이터 · 스코프

핵심 설계 판단: **1단계 브랜드사는 "운영자"가 아니라 "관전자+평가자"다.** 캠페인 개설·크리에이터 모집·시딩 물류는 전부 ARBAIM 대행. 브랜드 화면에서 쓰기(write) 권한은 딱 두 개만 준다 — **루브릭 평가**와 **2차 초대 선택**. 나머지는 전부 읽기 전용. 이렇게 해야 UX가 단순해지고, "우리가 다 해드린다"는 대행 가치가 화면에 그대로 드러난다.

|---|---|---|---|---|---|
| 0 | 패키지 계약 | 오프라인 영업 (앱 밖) | 제안서, 견적 | `brand_account` 생성(사명, 담당자, 티어=FGI), `invite_code` 발급 | 서버 필요 (mock: 하드코딩 코드 1개) |

| 5 | 평가 | 리뷰 평가 탭 (기존 v1 유지, §4에서 개편) | 리뷰 카드 + 루브릭 | `evaluation` 레코드 | mock 가능 (v1 존재) |
| 6 | 리포트 수령 | 대시보드 상단 "FGI 리포트" 배너 + 오프라인 PDF/미팅 | §5 리포트. 앱에는 요약판, 풀버전은 대면 브리핑 | 리포트는 앱 데이터 + ARBAIM 애널리스트 해석의 결합물 | 리포트 자체는 **수동 제작** (앱은 다운로드 링크만, mock 가능) |

> **여정상 가장 중요한 비화면 설계**: 3~4단계 사이 **주간 요약 알림**(푸시/이메일: "이번 주 신규 업로드 7건, 베트남 평균 4.2점"). 브랜드 담당자가 앱을 자발적으로 여는 빈도는 낮다. 알림이 재방문을 만들고, 재방문이 2차 결제를 만든다. 1단계는 이메일 수동 발송으로 대체 가능 (서버 필요 없음, 운영 프로세스).

## 2. 데이터 스키마 — "무슨 데이터를 쌓을 것인가" (세영 질문에 대한 직접 답변)

원칙 3개.

- **원칙 A — 리포트 역산**: §5 리포트 목차에 등장하는 숫자는 전부 필드로 쌓는다. 리포트에 안 들어가는 건 1단계에서 안 쌓는다.
- **원칙 B — 파생값은 저장하지 않는다**: 이행률, 업로드 소요일, 평균 점수는 타임스탬프·원본값에서 계산. 저장하면 나중에 반드시 어긋난다.
- **원칙 C — SNS 정량 지표는 1단계 수동 입력**: API 연동(YouTube/TikTok/IG)은 인증·쿼터·계정 연결 UX가 무겁다. 1단계 물량(캠페인당 리뷰 ~100건)이면 ARBAIM 운영자가 업로드 후 7일차·30일차에 조회수/좋아요를 수기 입력하는 게 압도적으로 싸다. 대신 `metrics_source: 'manual'`과 `captured_at`을 반드시 남겨 2단계 API 전환 시 데이터 계보가 끊기지 않게 한다.

## 3. 대시보드 고도화 — "돈 낸 보람" 화면

국가별 바 차트 하나가 약한 이유: **비교와 발견이 없기 때문**이다. FGI의 세일즈 포인트가 "몰랐던 시장 발견"이라면, 대시보드의 주인공은 차트가 아니라 **"발견(Finding)"이라는 편집된 문장**이어야 한다.

### 구성 (위→아래 순서 = 브랜드 임원 보고 순서)

| 영역 | 내용 | 왜 이게 "보람"인가 | 스코프 |
|---|---|---|---|
| ① 요약 카드 4장 | 총 업로드 N건 / 총 도달(수동 집계 뷰) / 평균 루브릭 점수 / **참여 국가 수** | 담당자가 상사에게 캡처 한 장으로 보고 가능한 단위. "5개국 87건, 42만 뷰" | **mock** |
| ② **위클리 발견 카드** (ARBAIM 애널리스트 작성 1~2문장) | "🇮🇳 인도: 예상 밖 25-34 남성 반응. '두피 쿨링' 언급 12건" | FGI가 리서치 서비스임을 증명하는 유일한 요소. 자동화 불가·불필요 — 운영자가 CMS성 텍스트 필드에 주 1회 입력 | **mock (텍스트 필드), 반드시 1단계** |
| ③ 국가 스코어보드 (기존 바 차트 대체) | 국가별 행: 이행률 / 평균 점수 / 평균 도달 / 업로드 소요일 — **정렬 가능한 테이블+미니바** | 바 차트 1개 → 4지표 비교. "어느 나라에 2차 3천만원을 걸까"라는 질문에 직접 답함 | mock |
| ④ 베스트 리뷰 하이라이트 릴 | 루브릭 상위 5~10건 영상 썸네일 가로 스크롤, 탭하면 원본 | 감정적 보람의 정점. 브랜드 대표가 "우리 제품을 외국인이 이렇게 말한다"를 직접 봄. **사내 공유 1순위 콘텐츠** | mock |
| ⑤ "다음 단계" CTA | 최고 성과 국가 명시 + "2차 캠페인 상담" 버튼 (§1-7) | 업셀 트리거 | mock |
| — 국가×연령 히트맵 | — | 셀당 표본 2~3명이라 1개 캠페인 규모(100건/5개국/4연령)에선 통계적으로 무의미. **리포트에서 애널리스트 해석과 함께 제시**하고, 앱 내 인터랙티브 히트맵은 캠페인 누적 후 | **2단계** |
| — 시계열 추이, 실시간 지표 | — | 수동 입력 데이터로 실시간 연출하면 신뢰 훼손 | 2단계(API 연동 후) |
| — 리포트 내보내기 | 대시보드에 "리포트 다운로드" 버튼만 (PDF는 ARBAIM 수동 제작·업로드) | 자동 PDF 생성은 엔지니어링 낭비. 수동 제작 리포트가 오히려 프리미엄 근거 | 버튼 mock / 자동생성은 **2단계 이후도 회의적** |

**핵심 주장 하나만 남긴다면**: ②번 위클리 발견 카드. 개발 비용은 텍스트 필드 하나지만, 이것이 있어야 대시보드가 "차트 모음"이 아니라 "리서치 서비스"가 된다. 없으면 브랜드는 1천만원과 무료 인플루언서 툴의 차이를 못 느낀다.

| 진정성 | **유지** | UGC의 본질 가치. 브랜드가 실제 궁금해함 |
| 제품 전달력 | **유지하되 기준 명시** | "content_guide 필수 포인트 중 몇 개를 자연스럽게 전달했나"로 평가 가이드 문구를 붙여야 점수가 국가·평가자 간 비교 가능해짐 |
| 콘텐츠 품질 | **유지** | 2차 초대(공구 판매력) 예측 변수 |
| 재협업 의향 | **5점 척도에서 제거 → Y/N 플래그로 분리** | 이건 리뷰 평가가 아니라 **의사결정**이다. "3점의 재협업 의향"은 해석 불가능한 데이터. Y/N이면 2차 초대 목록이 평균 정렬 없이 바로 나옴 |
| (신규) **시장 반응 시그널** 5점 | **추가 제안** | 브랜드가 진짜 궁금한 것: "이 콘텐츠/이 시장이 먹히나". 댓글 반응·크리에이터의 솔직 피드백("향이 강하다는 반응이 많아요")을 브랜드 시선으로 채점. FGI 상품 정체성과 정합. 단, 평가 부담을 고려해 **베스트 후보 리뷰에만 노출**하는 조건부 항목으로 |

→ 결과: **정량 4항목(진정성/전달력/품질/반응 시그널) + 재협업 Y/N + 코멘트(선택)**.

## 5. FGI 리포트 상품화 — 목차 제안

이 리포트가 "글로벌 FGI 4~5천만원 → 1천만원" 주장의 실물이자, 3천만원 2단계의 세일즈 덱이다. 형태: 25~35p PDF + 60분 대면 브리핑. **마지막 장이 항상 2단계 제안서로 끝나는 구조**가 상품화의 요체다.

| 장 | 제목 | 내용 | 데이터 원천 (→ §2 필드와 1:1 대응) |
|---|---|---|---|
| 0 | Executive Summary (1p) | 결론 3줄: 최우선 진출 시장 1곳, 핵심 소구점 1개, 권고 액션 | 애널리스트 |
| 1 | 캠페인 개요 | 제품/국가/시딩 규모/기간/참여 크리에이터 프로필 분포 | campaign, creator |
| 2 | 이행 및 도달 성과 | 퍼널(선정→수령→업로드), 국가별 이행률, 총 도달·CPE ("동일 도달 광고비 환산 시 X원" — 가격 정당화 문단) | seeding_status, views@7d/30d, product_cost |
| 3 | **국가별 시장 반응** (본론, 국가당 2~3p) | 국가별: 정량(이행률/점수/도달) + 정성(리뷰 발췌 인용, 반복 등장 키워드, 현지 언어 뉘앙스) + **"의외의 발견"** 박스 (인도 샴푸 스토리의 재현 슬롯) | review, evaluation, 애널리스트 발췌 |
| 4 | 콘텐츠 인사이트 | 어떤 제작 방식(format×production_style)이 어느 시장에서 반응했나 / 브랜드 루브릭 상위 리뷰 공통점 / 필수 메시지 전달률 | format, production_style, content_guide 대비 분석 |
| 5 | 세그먼트 스냅샷 | 국가×연령×성별 요약표 — 히트맵 대신 표+각주("표본 한계상 방향성 참고") | age_band, gender (§3에서 앱 히트맵을 뺀 이유가 여기서 해소됨) |
| 6 | 크리에이터 리더보드 | 베스트 N명 프로필·성과·재협업 확정 여부 — **2차 캠페인의 확정된 자산**으로 프레이밍 | evaluation, rebook_flag, follower_band |
| 7 | **Go-to-Market 권고 + 2단계 제안** | "1순위 인도네시아: 공구 파트너 후보 6명 확보, 예상 도달 X. 2단계 패키지(3천만원) 구성안" | 전체 종합 |
| 부록 | 전체 리뷰 링크 인덱스, 원자료 표 | 투명성 = 신뢰 = 재계약 | review 전체 |

- 스코프: 리포트 생산은 **전 과정 수동(애널리스트)**. 앱은 §1-6의 다운로드 배너만. 자동화하지 않는 것이 1단계의 올바른 결정 — 캠페인 월 2~3건 규모에서 자동화는 손해고, "사람이 해석해줬다"가 곧 FGI의 가격표다.
- 단, **목차의 모든 숫자는 §2 스키마에서 쿼리 한 번으로 나와야 한다**. 리포트 제작에 3일 이상 걸리면 스키마가 틀린 것이다 — 이게 세영에게 줄 검수 기준.
