## 1. 한 줄 정의와 북극성 지표

**한 줄 정의 (C 채택, 확정):**
> EN: "greyd — The invite-only panel where Korean brands actually read your review."
> KO: "greyd — 한국 브랜드가 당신의 리뷰를 직접 읽는, 초대제 패널."

**북극성 지표: 검증 루프 완료율 (Loop Completion Rate) — C 채택**
- 정의: 제품 **수령 확인(received)** 크리에이터 중 [리뷰 업로드 → 브랜드 평가(트리아지 이상) 수신]까지 완료한 비율. (수정: 분모를 A의 상태머신 `received` 기준으로 명확화 — 배송 리드타임 편차 제거)
- 1단계 목표: **70%** · 절대량: 3개월 내 완료 루프 **300건, 참여 브랜드 5곳**

**가드레일 지표 (C 채택, 일부 수정):**

| 지표 | 목표 | 비고 |
|---|---|---|
| 수령→업로드 중앙값 | ≤ 14일 | A의 D+14 타이머와 정합 |
| 리뷰 제출자 30일 재참여율 | ≥ 40% | A의 K7(재신청률 60%)은 내부 보조 지표로 유지 |
| 브랜드 평가 응답 시간 | ≤ 7일 | 트리아지 1차 기준 (풀 루브릭 아님) |
| 초대 코드 사용률 | 발급분의 ≥ 50% | 추천 코드 포함 |
| 앱스토어 평점 | ≥ 4.3 | "사기 같다" 인상 외부 지표 |

DAU/MAU는 2단계 이관. A의 여정 KPI(K1~K7)는 운영 퍼널 진단용 서브 지표로 채택.

### 3-2. 상태머신 enum 최종 정의

```
applied → approved → shipped → received → reviewing → done
              ↘ cancelled (주소 미입력 48h / 본인 취소 — 페널티 없음)
received ─(D+16 미업로드)→ no_show (Strike 부여)
```

| 값 | 의미 | 신규 여부 |
|---|---|---|
| `applied` | 신청 완료 | 기존 |
| `approved` | 선정 (주소 입력 대기 포함) | 기존 |
| `shipped` | 발송 (운송장 운영 수동 입력) | 기존 |
| `received` | **수령 확인 — D+14 타이머 기점, 북극성 분모** | **신규** |
| `reviewing` | 업로드 완료, 브랜드 확인 중 (`uploaded_at` 기록) | 기존 |
| `done` | 평가 완료·포인트 지급 | 기존 |
| `cancelled` | 무페널티 종결 | **신규** |
| `no_show` | 먹튀 확정 종결 (B의 이행 데이터 축) | **신규** |

**ops 매핑(v2.4, I3)**: 이 enum은 앱 표면의 상태이며, 정본은 ops `Match`/`Shipment`다 — applied↔ACCEPTED · approved↔CONFIRMED · shipped↔Shipment.SHIPPED · received↔DELIVERED+수령확인 · reviewing↔POSTED(+greyd_uploaded) · done↔Seeding DONE · cancelled/no_show↔DROPPED(사유 구분). 앱 인바운드 신청은 ops에 Match를 ACCEPTED로 생성한다(섭외 생략). 전체 표는 정합 문서 I3.

## 4. 정책 카드 (최종 수치 확정본)

### 4-1. 신청 유형 2종 (applyMode — I1 정합)

용어 정정(v2.4): "트랙"은 ops의 캠페인 상품 유형(PARTNERS/SEEDING/VISIT)을 가리키는 예약어다. 앱 체험 탭에 노출되는 것은 **ops SEEDING 트랙 캠페인**뿐이며, 아래 Open/Curated는 트랙이 아니라 SEEDING 캠페인의 **신청 유형(`campaign.applyMode`)**이다.

| | **Open** | **Curated** |
|---|---|---|
| 자격 | SNS 핸들 연결만 (팔로워 0 가능) | **G-스코어 60 이상 또는 완주 2회** |
| 승인 | 선착순 자동(mock 카운트, 실집행 운영) | 운영/브랜드 수동 |
| 물량 배분 | 전체의 **30%** | **70%** |
| 포인트 | Base 그대로 | Base × 등급 배수 |
| 목록 표기 | `Open · 선착순 N개 남음` 초록 배지 | `Curated` + 미달 시 잠금: "G60 달성 시 신청 가능" — **숨기지 말고 잠가서 보여준다** |

동시 진행 한도: 이력 0회 **1건** / G50~79 **2건** / G80+ **3건**.

### 4-2. Strike (먹튀 방어)

| 상태 | 조건 | 결과 |
|---|---|---|
| Strike 1 | received 후 D+16까지 미업로드 (`no_show`) | G-스코어 **−10**, 30일 Curated 잠금, 해당 캠페인 0P. 본인만 보이는 경고 카드 |
| Strike 2 | 2번째 미이행 | 영구 차단 (집행: 1단계 운영 수동) |
| 소멸 | Strike 1 후 연속 3회 완주 | Strike 0 복귀 (감점 회복은 별도) |
| Strike 아님 | 주소 미입력 취소 / 배송 사고 신고(2단계) / 연장 기한 내 업로드 | — |

유예: D+14~16 업로드 인정, 포인트 ×0.7.

### 4-3. 포인트 공식

```
지급 P = Base(100~500, 캠페인별) × 등급 배수 × 품질 보너스 × 유예 감액
```

| 요소 | 확정값 |
|---|---|
| Base | 세럼 1개+15초 = 200P / 3종 세트+60초 = 400P (브랜드·운영 설정) |
| 등급 배수 | G50~59 ×1.0 / G60~79 ×1.1 / G80~99 ×1.25 / G100+ ×1.5 — 캠페인 카드에 개인화 표시: "기본 300P · G80 달성 시 375P" |

## 4.5 역할별 IA (v2.1 추가 — D9)

**결정 D9: 사용자 유형별로 목적과 사용 루트가 다르므로, 진입 후 탭 구조 자체를 역할로 분기한다.**
브랜드가 크리에이터용 탭(홈 피드/체험/활동)을 보다가 마이페이지에서 캠페인 관리로 진입하는 v2 구조를 폐기 — 브랜드에게 그 3개 탭은 전부 소음이다.

| 역할 | 오는 이유 | 탭 구조 | 첫 화면 |

## 5. 브랜드 경험 최종안 (B 기반)

**대원칙: 브랜드 = 관전자+평가자.** 쓰기 권한은 ①트리아지/루브릭 평가 ②2차 관심 CTA 클릭, 둘뿐. 나머지 전부 읽기 전용 — 대행 가치가 화면 구조로 드러난다. (v2.1: 이 원칙이 §4.5의 역할별 탭 분리로 IA 레벨에서 완성된다 — 브랜드의 홈이 곧 대시보드다.)

### 5-1. 여정 (1단계 구현분)

| 단계 | 화면 | 1단계 |
|---|---|---|
| 입장 | 초대 코드(role=brand) → 온보딩 1장: "캠페인은 ARBAIM이 개설·운영합니다. 결과를 보고 평가만 하세요" | mock |
| 모니터링 | 캠페인 홈: 대시보드(§5-3) | mock |
| 평가 | 트리아지 → 후보 루브릭(§5-2) | mock |
| 리포트 | "FGI 리포트 다운로드" 배너 (PDF는 애널리스트 수동 제작) | 배너만 |
| 2차 결정 | "다음 단계" CTA(§5-3-⑤) | mock + 클릭 이벤트 기록 |
| 재방문 | 주간 요약 이메일 — 운영 수동 발송 | 운영 프로세스 |

시딩 퍼널 타임라인·콘텐츠 피드는 2단계(§9) — 대시보드 요약 카드가 1단계에선 대체.

### 5-2. 트리아지 + 루브릭 최종형 (D3 확정)

1. **1차 트리아지**: 리뷰 카드 스와이프, 3버튼 — 👍 후보 / 👌 보통 / 👎 스킵(사유 enum: 저품질/가이드 위반/판단 불가). 100건 10분 목표.
2. **2차 정량 (👍 후보 ~상위 20%에만)**: 4항목×5점 — 진정성 / 제품 전달력(content_guide 필수 포인트 전달 개수 기준 문구 병기) / 콘텐츠 품질 / 시장 반응 시그널 + **재협업 Y/N** + 코멘트(선택).
3. 진행률 게이지 + "20건만 평가해도 리포트 정확도는 충분해요" 안내. 일괄 평가 기능은 만들지 않는다.

### 5-3. 대시보드 구성 (위→아래 = 임원 보고 순서)

| # | 영역 | 내용 |
|---|---|---|
| ① | 요약 카드 4장 | 총 업로드 / 총 도달(수동 집계, `수집일` 표기) / 평균 루브릭 점수 / 참여 국가 수 |
| ② | **위클리 발견 카드** | 애널리스트 작성 1~2문장 (예: "🇮🇩 예상 밖 25-34 남성 반응, '쿨링' 언급 12건"). mock은 텍스트 필드 — **1단계 필수, 이게 없으면 차트 모음이지 리서치 서비스가 아니다** |
| ③ | 국가 스코어보드 | v1 바 차트 **대체**: 국가별 이행률/평균 점수/평균 도달/업로드 소요일, 정렬 가능한 테이블+미니바 |
| ④ | 2차 CTA | "이행률 92% · 평균 4.4점 인도네시아 — 2차 공구 캠페인 견적 보기" → 클릭 = 세일즈 리드 이벤트 |

베스트 하이라이트 릴·히트맵·시계열은 §9로 컷.
