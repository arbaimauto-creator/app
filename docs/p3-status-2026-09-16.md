## 앱 검증
- Jest 125/125, ESLint 오류 0, Android 번들 컴파일 정상.
- 새 화면(본인확인·장바구니·주문 내역·FGI 카드)은 **로그인 계정과 ops 배포가 있어야** 실제 데이터로 볼 수 있다. 게스트 에뮬레이터에선 진입점만 확인 가능.

## ops 검증
- `tsc --noEmit` 통과, vitest 124 통과. 스키마 변경 3건(`MobileVerification`, `Influencer.identityVerifiedAt`, `Match.fgiSelection/fgiAttendedAt`)은 배포 시 `prisma db push` 필요.
