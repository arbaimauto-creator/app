# 쇼츠 상품 카드 · 구매 버튼 기능정의 (초안, 2026-09-15)

앱 안에서 바로 살 수 없는 상품을 눌렀을 때 "데이터 없음"류 안내만 뜨는 문제.
코드를 고치기 전에 무엇을 보여줄지부터 정한다.

## 지금 코드가 하는 일 (사실)

| 상황 | 쇼츠 카드 | 카드 탭 | Buy 버튼 |
|---|---|---|---|
| 앱 내 상품 (`productId` 있음, `externalLink` 없음) | 썸네일·이름·가격 | ProductPage 이동 | 노출. `FEATURES.COMMERCE=false`라 누르면 영어 알럿 "Unavailable / Ordering is not available in this version." |
| 외부 링크 상품 (`externalLink` 있음) | 썸네일·이름·가격 | ProductPage 이동 → "최저가 확인" 링크 행만 의미 있음 | 미노출 |
| 게스트 | 위와 같음 | 상세 시트에 "로그인하고 최저가 확인" 문구 | 로그인 알럿 |
| 연결 상품 없음 / 삭제(`statusCode=1`) | 카드 자체 미노출 | — | — |

- 커머스 플래그가 꺼져 있어(1단계 클로즈드 앱) 앱 내 결제는 어느 상품이든 실제로 동작하지 않는다.
- 외부 링크 상품은 "구매 불가"가 아니라 "앱 밖에서 구매"인데, 카드 탭이 ProductPage(주문 화면)로 가는 게 어긋난다.

## 정해야 할 것

1. 1단계(커머스 OFF) 동안 상품 카드의 역할: **정보 안내**인가 **구매 유도**인가.
2. 외부 링크 상품은 앱 안에서 링크를 **바로 여는가**(외부 브라우저) / 상품 페이지를 거치는가.
3. 앱 내 상품인데 커머스가 꺼진 경우 버튼을 **숨길지**, **"준비 중"으로 보여줄지**.

## 제안 (권장안)

| 상품 종류 | 카드 | 버튼 | 누르면 |
|---|---|---|---|
| 외부 링크 상품 | 썸네일·이름·(가격 있으면) 가격 · "외부 사이트" 뱃지 | **"사러 가기"** | `Linking.openURL(externalLink)`. 열기 실패 시 "링크를 열 수 없어요" 토스트 |
| 앱 내 상품, 커머스 OFF | 썸네일·이름·가격 | 버튼 없음 | 카드 탭 → ProductPage(정보만, 주문 UI 숨김). 상단에 "앱 내 구매는 준비 중" 노트 |
| 앱 내 상품, 커머스 ON | 지금과 동일 | "구매" | 지금과 동일(구매 팝업) |
| 게스트 | 위와 동일 | 위와 동일 | 외부 링크는 로그인 없이 열어도 됨(막을 이유 없음). 앱 내 구매만 로그인 알럿 |

- "데이터 없음" 같은 실패 문구는 어떤 경우에도 사용자에게 보이지 않게 한다. 데이터가 정말 없으면 카드를 숨긴다(지금 규칙 유지).
- 문구는 Strings에 한/영 추가: `PRODUCT_GO_TO_STORE`(사러 가기), `PRODUCT_EXTERNAL_BADGE`(외부 사이트), `PRODUCT_IN_APP_SOON`(앱 내 구매는 준비 중), `PRODUCT_LINK_OPEN_FAILED`.
- 서버 변경 없음. 모두 클라이언트에서 `externalLink` 유무와 `FEATURES.COMMERCE`로 분기.

## 확인 필요

- 외부 링크 상품의 가격이 서버에서 오는지(현재 `price`가 0이면 가격을 숨김).
- 외부 사이트로 보낼 때 제휴 파라미터(UTM 등)를 붙일지.

이 안대로 가면 구현은 `VideoOverlay.js` ProductCard 분기 + `ProductPageScreen.js` 주문 UI 숨김 + Strings 4개, 반나절 분량이다.
