# 디자인 고도화 "Maison" (2026-09-30)

> 대표 요청: "앱 전체 디자인을 고급스럽고 세련되게."
> 방향: 기존 웜 골드 글래스 컨셉(9/17)을 버리지 않고 **절제된 럭셔리**로 정제한다 — 채도를 낮추고, 굵기를 덜고, 금색은 면이 아닌 선·점으로.
> 비교 이미지: `docs/design-refresh-2026-09-30-compare.png` (실제 화면 코드를 react-native-web으로 렌더링한 캡처. 실기기 캡처 아님)

## 1. 원칙

1. **금색은 액센트다.** 채도 높은 앰버(#FFB731) 면 → 샴페인 브론즈(#B08D57)의 선·점·작은 강조. 넓은 금색 면은 쓰지 않는다.
2. **주 버튼은 에스프레소.** 광택 앰버 → 에스프레소 무광 알약 + 아이보리 글자 + 샴페인 헤어라인. 금색 버튼은 `variant="gold"`로 보조 강조에만.
3. **가볍게.** 한글 굵기를 한 단계씩 낮춘다(ExtraBold→Bold→SemiBold). 무거운 굵기가 "싸 보이는" 가장 큰 원인이었다.
4. **숫자와 로고는 세리프.** Cormorant Garamond(라이닝 숫자로 고정)로 G-스코어·포인트·가격·워드마크. 한글 글리프가 없으므로 **라틴/숫자만 있는 자리**에만 쓴다.
5. **헤어라인과 여백.** 두꺼운 테두리·그림자 대신 0.5px 선, 넓고 옅은 그림자. 배경 오브는 샴페인 안개 수준으로 옅게.
6. **이모지 대신 라인 아이콘.** 빈 상태·완료 화면의 이모지 → 샴페인 원 안의 라인 아이콘(`EmptyIcon`).

- 토큰 **이름**(AMBER 등)은 163개 화면 호환을 위해 유지했다. `AMBER` = "브랜드 골드"로 읽는다.
- `FONT.ExtraBold`/`Black`/`Bold`는 이름은 그대로, 실제 파일을 한 단계 가볍게 매핑했다(주석 참고).
- `TYPE.KPI / NUM / NUM_XL / DISPLAY_*`는 세리프. `TYPE.BTN` 글자색은 `ON_INK`.
- 레거시 `Constants/Style.js`의 `COLOR_MAIN` 등도 같은 값으로 맞췄다. 웹(`web/src/styles.css`)도 동일 값.

## 4. 화면별로 손본 곳

- **하단 탭바**: 평평한 아이보리 바 + 헤어라인, 머티리얼 활성 알약 제거, 활성은 에스프레소 아이콘·라벨 + 위쪽 작은 골드 마커.
- **홈**: 헤더 아이콘 헤어라인, G 배지 세리프, 스토리 링 샴페인, "리뷰 올리기" 카드 글래스 + 에스프레소 버튼.
- **금색 면 + 흰/아이보리 글자 CTA**(대비 부족): 체험 상세·FGI 설문·체험 목록 수락·판매자 버튼·알림 액션 → 에스프레소.
- **큰 숫자**(G-스코어·포인트·가격·인증번호): 세리프 라이닝 숫자.
- **공동구매**: 가격 세리프 + 한글 단위 분리(`Price`), 이모지 자리표시 → 라인 아이콘.
- **로고 텍스트**: 로그인·온보딩·피드 빈 상태·About → 세리프 워드마크. 온보딩 영문 부제는 세리프 이탤릭(한국어 화면에서만).
- **이모지 빈 상태 15곳** → `EmptyIcon`.

## 5. 네이티브 반영 (재빌드 필요)

- 폰트 4개: `assets/fonts`, `ios/fonts`, `android/app/src/main/assets/fonts`에 `CormorantGaramond-{Medium,SemiBold,Bold,MediumItalic}.ttf`, `ios/greyd/Info.plist` `UIAppFonts` 추가. 라이선스 `assets/fonts/CormorantGaramond-OFL.txt`(SIL OFL).
  - 가변 폰트를 정적 굵기로 고정하고, 숫자를 라이닝(높이가 고른) 숫자로 기본 설정했다. PostScript 이름 = 파일 이름(iOS·Android 모두 `fontFamily: 'CormorantGaramond-SemiBold'`로 찾음).
- **JS만 OTA로 먼저 나가면** 세리프 자리가 시스템 폰트로 대체된다(깨지지는 않음). 네이티브 빌드와 함께 배포할 것.

## 6. 남은 것 (다음 라운드 후보)

- 쇼츠(영상) 화면 오버레이·댓글 시트, 브랜드 대시보드 차트 색 — 이번엔 토큰으로만 반영, 개별 디자인 패스는 안 함.
- 레거시 화면(구 상품·주문·B2B)은 토큰 연동분만 바뀐다. 하드코딩 회색(#a0a0a0 등) 정리는 별도.
- 실기기에서 블러·그림자 강도 최종 확인(웹 미리보기와 네이티브 렌더가 다를 수 있다).
